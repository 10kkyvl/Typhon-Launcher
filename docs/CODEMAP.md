# Typhon Launcher — Code map

Dense per-file map. Columns: what the file owns, symbols worth knowing, who calls it / what it calls, which flow (`FLOWS.md`) passes through, when to open it. References are `path::Symbol`. Generated files (`frontend/bindings/`, `frontend/dist/`, `build/*` scaffolds) and one-line platform stubs are omitted. Working tree of 2026-09-11; see [INDEX.md](INDEX.md) for reading and evidence policy.
