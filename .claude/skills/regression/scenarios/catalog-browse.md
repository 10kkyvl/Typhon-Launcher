# Каталог листается, ищет, фильтрует и открывает игру

Ловит поломки контракта с живым бэкендом (прод API), которые моки в тестах не видят,
потерю кликов по фильтрам во время загрузки и шум диагностики при быстрой смене фильтров.

## Шаги

1. `click 'Все игры'`.
   ожидание: за 10 с в DOM больше 10 карточек
   (`eval "document.querySelectorAll('div.card span.title').length"`). Сверху полки
   рекомендаций «Для тебя», ниже сетка.
2. `fill 'input[placeholder="Поиск по каталогу"]' 'witcher'` (поле в шапке — глобальный
   поиск, не каталог).
   ожидание: среди `div.card span.title` есть название с «Witcher». Затем очистить поле.
3. Эталон: одиночный клик по чипу «Гонки», дождаться конца загрузки
   (`section.recommendations` без `aria-busy="true"`), запомнить первые 10 названий сетки.
   Вернуть «Все» (повторный клик по выбранному чипу снимает выбор).
4. Залп через `eval` прямо в странице: по очереди `click()` по чипам «Экшен»,
   «Приключения», «Аркады», «Инди», «Гонки» с интервалом 100 мс.
   ожидание через 4 с: выбран ровно «Гонки» (`button.chip.selected`), первые 10 названий
   совпадают с эталоном шага 3; в логе за эти секунды нет `window.unhandledrejection` и
   `context canceled`; в console допустим только `422 /wails/runtime` от отменённых вызовов.
5. Открыть первую карточку сетки (не полки рекомендаций).
   ожидание: `wait 'Загружаем сведения об игре' 15000 --gone`, после этого описание длиннее
   100 символов и обложка загружена.
6. `click 'Назад'`.
   ожидание: выбран тот же жанр; `main.content.scrollTop` такой же, как перед открытием.

## Доказательства

- Скриншоты шагов 1, 4, 5.
- Эталон и результат залпа (названия), строки лога шага 4.

## Уборка

Снять жанр (повторный клик по выбранному чипу) и очистить поиск. Чип «Скрыть неинтересные»
включён по умолчанию — его не трогать.
