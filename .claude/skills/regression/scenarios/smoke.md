# Лаунчер стартует, все разделы открываются без ошибок

Ловит то, что тесты не видят: белый экран после обновы фронтенда, раздел, падающий на
реальных данных пользователя, исключения в консоли, ошибки старта сервисов в логе.

## Подготовка

- Перезапустить qa-сборку и сразу подключиться: `console 8000 --connect-ms 15000` — только
  так видны исключения старта.
- Отметка в логе: номер последней строки с `qa build: CDP on`.

## Шаги

1. `targets`.
   ожидание: среди целей ровно одна страница `http://wails.localhost/` (вторая, `data:`, —
   служебный шим Wails); заголовок процесса `Typhon [qa]`
   (`(Get-Process typhon).MainWindowTitle`).
2. Вывод `console` из подготовки.
   ожидание: нет `Uncaught`, `TypeError`, `unhandledrejection`. Известный шум — в SKILL.md.
3. По очереди: `click 'Библиотека'`, `'Все игры'`, `'Установлено'`, `'Загрузки'`,
   `'Источники'`, `'Друзья'`, `'Активность'`, `'История'`, `'Настройки'`.
   ожидание для каждого: `text --limit 20000` не пустой, нет «не удалось выполнить
   операцию», «Ошибка загрузки», `undefined`, `[object Object]`, `NaN`, ключей вида `ui.xxx`.
   Исключение — строки «Истории» и бейджи о сбоях, случившихся до прогона: сверять по полю
   `at` записей `history.json`, это записи о прошлом, а не поломка раздела.
   Скриншот каждого раздела.
4. Меню пользователя (`click` по имени пользователя в сайдбаре), затем `click 'Профиль'`.
   В том же меню статусы и «Выйти» — их не нажимать.
   ожидание: имя пользователя на странице, если сессия есть.
5. Лог после отметки.
   ожидание: строка `typhon starting` с текущей версией; нет `panic` и `level=ERROR`; каждый
   `WARN`, кроме известного шума из SKILL.md, выписать дословно.

## Доказательства

- Скриншоты всех разделов.
- Дословный вывод `console` и все строки `level=ERROR|WARN` за время сценария.

## Уборка

Не нужна.
