# Игра запускается, сессия учитывается, «Стоп» её закрывает

Детект процессов, учёт времени и «Стоп» работают с настоящими процессами Windows и
лаунчерами игр, которые перезапускают себя. Тесты покрывают логику, но не реальные
процессы. Проходить только по явному заданию: сценарий запускает игру у пользователя.

## Подготовка

- В «Установлено» есть игра с исполняемым файлом. Выбрать самую лёгкую. Нет — `ПРОПУЩЕН`.
- Запомнить её `playtime` из `playlog.json`/`library.json`.

## Шаги

1. Открыть игру, `click 'Играть'`.
   ожидание: за 30 с процесс игры есть в `Get-Process`, в UI статус «Играет».
2. Подождать 60 с.
3. `click 'Стоп'`.
   ожидание: процесс игры исчез за 15 с, статус вернулся, время игры выросло примерно на
   минуту, в логе нет `level=ERROR`.
4. Игра без исполняемого файла (если есть такая в библиотеке).
   ожидание: кнопки «Играть» нет.

## Доказательства

- Выдержки `playlog.json` до и после.
- Скриншоты шагов 1 и 3.

## Уборка

Убедиться, что процесса игры нет.
