# Сессия переживает перезапуск, друзья и чат открываются

Ловит слом контракта с прод-бэкендом и потерю токена в хранилище учётных данных после
обновы. Пароли агент не вводит: без сессии сценарий `ПРОПУЩЕН`.

## Шаги

1. Профиль из меню пользователя.
   ожидание: имя пользователя и аватар.
2. Перезапуск лаунчера.
   ожидание: сессия на месте (нет кнопки «Войти» в меню пользователя).
3. `click 'Друзья'`.
   ожидание: список или явная пустая заглушка, без текста ошибки.
4. Открыть чат с любым другом (если есть).
   ожидание: история сообщений загружается; в логе нет ошибок `chat/events`.
5. Лог: строки про presence.
   ожидание: нет `401`/`502` за время сценария.

## Доказательства

- Скриншоты шагов 1, 3, 4.

## Уборка

Не нужна. Сообщения не отправлять.
